# 유학상담시스템 목업 공유용 폴더

이 폴더는 팀원에게 전달하거나 정적 호스팅에 그대로 업로드할 수 있는 배포용 파일 묶음입니다.

## 포함 파일

- `index.html` — 전체 랜딩/진입 페이지
- `06_사용자_상담_목업.html` — 학생 모바일 목업
- `06b_학생포털_데스크톱_목업.html` — 학생 데스크톱 목업
- `07_관리자_상담관리_목업.html` — 대학 담당자 목업
- `08_플랫폼관리자_목업.html` — 플랫폼 관리자 목업

## 공유 방법

1. 파일로 전달할 때는 이 폴더 전체를 압축해서 전달합니다.
2. 팀원은 압축을 푼 뒤 `index.html`을 브라우저에서 열면 됩니다.
3. 서버에 올릴 때는 이 폴더 안의 파일들을 정적 호스팅 루트에 그대로 업로드하면 됩니다.

## 주의

- 5개 HTML 파일은 같은 폴더 안에 있어야 페이지 이동 링크가 정상 작동합니다.
- SQL 백업, 내부 명세서, 작업용 문서는 포함하지 않았습니다.
- 학생 개인정보는 포함하지 않았고, 학생 데이터는 목업용 더미 데이터입니다.
